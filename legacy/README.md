# Historical pilot scripts

These scripts are preserved for comparison with the current `src/aaeid/` package. The supported entry point is `python -m aaeid.run --config configs/default.yaml`, run from the repository root.

| Script | Stage |
|---|---|
| `aae_classifier_pilot.py` | Initial pilot |
| `aae_classifier_pilot_v2.py` | Second pilot |
| `aae_classifier_alignment_v3.py` | Third alignment pilot |

Read the [pilot audit](../docs/AUDIT.md) before interpreting results produced by these historical scripts.
